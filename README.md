# 面談メモ整理ツール（学習用の見本）

営業の面談メモ（走り書き）を、**事実**と**所感**に分けて整理する、Claude APIの練習用ツールです。
面談後の記録を、あとで見返しやすく、次の提案に使いやすい形にすることを目指しています。

損保営業の経験をもとに、「記録で困りやすい点」を、プロンプトに組み込みました。

## 何をするか

走り書きのメモを入れると、次の5つの見出しで出力します。

0. **基本情報**：日時・相手・形式（メモにあるものだけ）
1. **事実**：メモに書かれている発言・数字・日付
2. **所感**：書き手の印象や推測（「たぶん」「〜そう」など）
3. **次のアクション**：誰が・何を・いつまでに
4. **未確認事項**：メモからは分からず、確認が必要な点

## プロンプト設計の考え方

- **事実と所感を分ける**：「たぶん予算はある」のような推測が、事実として記録に残ると、次の提案を誤らせるためです
- **メモにないことは書かせない**：AIが想像で補わないよう、「記載なし」と書くルールにしました。最初の試しでは、メモにない「導入」という言葉を足されたので、「メモにない言葉を足さない」というルールを具体例つきで加えました
- **数字・固有名詞はそのまま**：言い換えによる誤りを防ぎます
- **出力の形を固定する**：見出しと箇条書きにして、あとで蓄積・検索しやすくしました

## 使い方

1. Python 3 と、Anthropicのライブラリを用意します。
   ```bash
   pip install anthropic
   ```
2. APIキーを、環境変数 `ANTHROPIC_API_KEY` に設定します（コードに書かないでください）。
3. 実行します。メモのファイルを指定しない場合は、サンプルの `sample_notes.txt` を使います。
   ```bash
   python3 organize_notes.py
   python3 organize_notes.py my_notes.txt
   ```

## 注意

- `sample_notes.txt` の会社名・人名は、すべて**架空**です。
- **実在のお客様・候補者の氏名や個人情報は、入力しないでください。** 実務で使う場合は、所属先のAI利用ルールと、データの取り扱い方針の確認が必要です。
- 出力は「下書き」です。重要な内容は、必ず自分の目で確認してください。
- 音声メモの文字起こしなどは、このツールでは扱っていません。

## 実行例（架空のメモ `sample_notes.txt` での、実際の出力）

```
**0. 基本情報**
- 日時：10/3 15:00
- 相手：架空商事（株）購買部 田中部長（仮名）
- 形式：オンライン面談

**1. 事実**
- 先方は、現行の問い合わせ対応が属人化していると話していた
- 月の問い合わせは約300件とのこと
- 決裁は役員会
- 担当は佐藤さん（仮名）

**2. 所感**
- たぶん予算はある
- 時期は年度末あたりか？
- 佐藤さん（仮名）は前向きそうだった
- 田中部長は、慎重な印象
- セキュリティ審査があるかも？

**3. 次のアクション**
- 私｜事例資料を送る｜次回まで
- 田中部長｜関係者を社内で確認する｜来週中

**4. 未確認事項**
- セキュリティ審査の有無（メモに「要確認」と記載）
- 予算の有無
- 時期（メモでは「年度末あたりか？」）
- 次回の日時：記載なし
```

## 改良の記録
最初の版では、メモにない「導入」という言葉を足された他、出力に余計な見出しや表が混ざっていました。プロンプトに、具体例つきのルールと、出力の形の指定を加えて、直しています。
